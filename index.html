Bienvenido a TelmatoFinder

La aplicación está alojada como un sitio web normal, pero el modelo y análisis acústico se ejecutan dentro de tu navegador utilizando ONNX Runtime Web.

Al subir tus audios, tu navegador ejecuta la inferencia localmente. Ningún archivo o dato es enviado a servidores externos.
